### Code Highlighting

Here's some TypeScript code:

```typescript
interface User {
  name: string;
  email: string;
  age?: number;
}

function greetUser(user: User): string {
  return `Hello, ${user.name}!`;
}

const user: User = {
  name: 'Alice',
  email: 'alice@example.com'
};

console.log(greetUser(user));
```

### Math is Beautiful

Did you know? The Gaussian integral is:

$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$

And here's Euler's identity, often called the most beautiful equation in mathematics:

$$
e^{i\pi} + 1 = 0
$$
